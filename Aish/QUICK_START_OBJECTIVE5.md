# 🚀 Quick Start - Objective 5

## Access in 3 Steps

### Step 1: Start Server
```bash
cd sustainable_energy
python manage.py runserver
```

### Step 2: Open Browser
Navigate to: **http://localhost:8000/**

### Step 3: Click Objective 5
Click: **"Objective 5: Policy Impact Tracking"** card

## What You'll See

1. **Global Statistics** - Click "Load Global Statistics"
   - Global average access
   - Countries tracked
   - Countries at 100%
   - Countries below 50%

2. **Model Comparison** - Click "Load Model Comparison"
   - Bar chart with MSE scores
   - Best model identified (XGBoost)

3. **Country Analysis** - Select country and click "Analyze Country"
   - Country statistics (4 cards)
   - Historical trends chart
   - Future predictions chart (2024-2030)
   - Combined historical + future view
