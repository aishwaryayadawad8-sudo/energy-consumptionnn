## 🎨 Customize Your Background

### Make it Brighter
Edit `sustainable_energy/static/css/electric-background.css`:
```css
/* Line 46 */
opacity: 0.9;  /* Change from 0.7 */
```

### Make it Pulse Faster
```css
/* Line 43 */
animation: electricPulse 2s ease-in-out infinite;  /* Change from 4s */
```

### Change the Color
```css
/* Line 35 */
rgba(0, 255, 255, 0.6)  /* Try brighter cyan */
```

## 🐛 Troubleshooting

### Background Not Showing?
```bash
# Clear browser cache
Ctrl + F5

# Or restart server
cd sustainable_energy
python manage.py runserver
```

### Email Alerts Not Working?
```python
# Check email_config.py
EMAIL_HOST_USER = 'your-email@gmail.com'
EMAIL_HOST_PASSWORD = 'your-app-password'
```

### Charts Not Loading?
```bash
# Clear browser cache and refresh
Ctrl + Shift + Delete
```
