# ✍️ Send Custom Alert to Country - Complete Guide

## Overview
A powerful page where you can select any country and write your own custom alert message. Perfect for sending personalized communications to countries about their energy situation.

## Access the Page

### From Home Page
1. Go to: http://127.0.0.1:8000/
2. Look for: **"✍️ Send Custom Alert"**
3. Click on the card

### Direct URL
```
http://127.0.0.1:8000/send-custom-alert/
```

## Features

### 🎯 Complete Customization
- Write your own email subject
- Create custom message content
- Full control over what you send

### 📝 Message Templates
Pre-written templates to get you started:
- **🚨 Urgent Alert** - For critical situations
- **📢 Reminder** - For follow-ups
- **🎉 Congratulations** - For achievements
- **📊 Status Update** - For progress reports

### 📊 Country Information
- See country name
- View email address
- Check current electricity access

### ✅ Character Counters
- Subject: 200 characters max
- Message: 2000 characters max
- Real-time character count

## How to Use

### Step 1: Select Country
1. Click the dropdown menu
2. Choose a country from the list
3. Country information will appear

### Step 2: Choose Template (Optional)
1. Click one of the template buttons:
   - 🚨 Urgent Alert
   - 📢 Reminder
   - 🎉 Congratulations
   - 📊 Status Update
2. Template will fill in subject and message
3. Edit as needed

### Step 3: Write Subject
1. Enter your email subject
2. Keep it clear and concise
3. Maximum 200 characters

### Step 4: Write Message
1. Type your custom message
2. Be professional and clear
3. Maximum 2000 characters
4. Use line breaks for readability

### Step 5: Send
1. Review your message
2. Click "Send Custom Alert"
3. Wait for confirmation

## Message Templates

**Subject:** 🚨 URGENT: Immediate Action Required - Electricity Access

**Message:**
```

URGENT ALERT: This is a critical notification regarding electricity 
access in your country.

Our monitoring system has identified areas requiring immediate attention. 
We recommend:

1. Assess current electricity infrastructure
2. Identify underserved regions
3. Develop emergency response plan
4. Coordinate with international partners

Please respond within 48 hours to discuss support options.

Best regards,
SDG 7 Global Monitoring Team
```

## Tips for Writing Good Messages

### DO:
✅ Be clear and professional  
✅ Use proper grammar and spelling  
✅ Include specific information  
✅ Provide actionable recommendations  
✅ Use a respectful tone  
✅ Include contact information  

### DON'T:
❌ Use all caps (except for emphasis)  
❌ Be vague or unclear  
❌ Use informal language  
❌ Make demands without explanation  
❌ Forget to proofread

## Troubleshooting

### Problem: Send button is disabled
**Solution:**
- Make sure you selected a country
- Enter an email subject
- Write a message
- All three are required

### Problem: Character limit reached
**Solution:**
- Subject: Max 200 characters
- Message: Max 2000 characters
- Edit your text to fit within limits

### Problem: Template not loading
**Solution:**
- Click the template button again
- Refresh the page
- Try a different template

### Problem: Email not sending
**Solution:**
- Check email configuration
- Verify SMTP settings
- Check server logs
- Try again
