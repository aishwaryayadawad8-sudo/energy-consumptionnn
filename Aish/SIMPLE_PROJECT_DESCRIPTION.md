# 🌍 Energy Access Dashboard - Simple Project Description

## What is this project?

This is a **website that shows electricity access around the world**. It helps people understand which countries have electricity and which ones don't.

## What can you do with it?

### 🔍 **Search for any country**
- Type a country name like "India" or "Germany"
- Select from a dropdown list of 68+ countries
- See results immediately on the map and charts

### 🗺️ **See countries on a world map**
- Interactive map that you can zoom and move
- When you search a country, it gets highlighted in green
- A pin shows exactly where the country is

### 📊 **View 4 different charts**
- **Timeline Chart**: Shows how electricity access changed over years
- **Pie Chart**: Shows what types of energy the country uses
- **Forecast Chart**: Predicts future electricity access
- **Growth Chart**: Shows renewable energy growth

### ⏰ **Choose different time periods**
- **All Years**: See data from 2000 to 2030
- **Historical**: Only past data (2000-2020)
- **Predictions**: Only future predictions (2021-2030)
- **Recent Trends**: Recent past + future (2015-2030)

## How does it work?

### Simple 3-step process:
1. **Search** for a country name
2. **See** the map highlight that country
3. **View** all the charts automatically appear

### No complicated buttons to click!
- Charts appear automatically when you search
- Just type and see results instantly
- Easy to use for anyone
